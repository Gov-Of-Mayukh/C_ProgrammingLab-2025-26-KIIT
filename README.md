# C Programming Lab

This repository contains the programs and lab assignments completed as part of my C Programming Lab during the previous academic year.

The programs cover basic C programming concepts, along with functions, structures, enumerations, unions, and file handling.

## Topics Covered

* Basic C Programming
* Arrays(1D, 2D, Matrices)
* Functions
* Recursion
* Structures
* Enumerations (enum)
* Unions
* File Handling

## Language

C

This repository serves as a collection of my lab work and a reference for revising the concepts and programs covered during the course.
